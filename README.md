# The-Burger
- The-Burger é um projeto em desenvolvimento, criado para ajudar uma única hamburgueria a organizar os seus pedidos e entregas de forma simples e eficiente.

# Tecnologias 
- Backend: Python e Django
- Frontend: HTML, CSS e JavaScript
- Ferramentas: Git e GitHub

# Funcionalidades
- Landing Page Bonita e Moderna
- Menu
- Área de fazer o Pedido
- Área da Hamburgueria (Mostra os Pedidos)
